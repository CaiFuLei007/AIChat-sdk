
你是一位资深独立设计师，专注于《反主流》的网页美学。你鄙视千篇一律的 SaaS 模板，认为软件界面应该有触感和灵魂。也是一位资深前端开发工程师。请使用 React + TypeScript + Tailwind CSS 等工具创建两个页面。
登录页面：
1. 邮箱密码登录，和注册账号两个功能
2. 将注册和登录两个放在同一个网页中可以切换登录还是注册，双tab可以切换
3. 注册的时候要还有确认密码字段，防止用户因手误设置了错误的密码。
4. 在密码和确认密码的输入框右侧，增加一个“显示/隐藏密码”（小眼睛图标）的切换按钮，
5. 表单验证（邮箱格式、密码长度至少8位）
6. 记住我的复选框
7. 加载动画和错误提示
8. 设计风格简约现代，配色为蓝白主题
9. 用户注册完成之后清空表单内容，高亮提示“注册成功，请切换至登录”

用户聊天界面：
1. 这是用户与模型交互的界面，显示用户和模型互相发送的消息
2. 大模型在回复时通常是流式输出的时候，输入框在此期间是否会被禁用
3. 聊天消息是否支持 Markdown 渲染，如果模型输出了代码块，需要包含代码高亮机制以及“一键复制”按钮
4. 当流式数据不断推送到前端时，页面需要自动向下滚动，保持最新生成的文字在可视区域内
5. 如果在流式输出期间，用户主动向上滚动鼠标滚轮去查看之前的上下文，系统必须立刻暂停自动下拉，并在右下角出现一个“回到最新/底部”的悬浮小按钮。
6. 输入框不要使用固定高度的单行 input，应使用可以根据输入内容自动撑高的多行 textarea，并设定一个最大高度（超过则内部滚动）。
7. 明确快捷键：Enter 键发送消息，Shift + Enter 进行换行输入。
8. 用户可以选择模型创建新会话，与大模型开始新的交流
9. 左侧有个侧边栏，可以折叠和打开
10. 侧边栏中包含与模型的所有历史会话，可以选择任意一个进行删除，也可以选择任意一个会话继续与接着之前的消息继续聊天
11. 侧边栏需要支持滚动
12. 在页面的左下角显示用户的信息，用户可以退出登录


创造边界：
现代但不要紫色：采用深灰 + 橙色体系
极简但要有温度：大留白 + 手绘装饰元素
科技感但不要冰冷：深色基底 + 暖色点缀提亮

禁止蓝紫渐变、科技绿主色调
禁止极光、WebGL、动态流光背景
禁止高斯模糊、大面积柔光阴影
拒绝绝对居中对称的刻板英雄区布局
摒弃同质化SaaS通用无衬线字体

设计要求：
色彩体系：奶白纸感底色 + 墨色正文 + 琥珀橙品牌主高光 + 沙土米辅助点缀
字体层级：衬线字体（标题/数据）+ Inter（正文）+ 等宽字体（标签/编号）
阴影样式：采用印刷式硬偏移阴影，无模糊效果，还原纸质质感
交互逻辑：hover 上浮位移、阴影加深，点击复位，自带物理反馈感
装饰元素：加入SVG波浪下划线、八芒星火花、虚线圆环、票据式标签
排版布局：杂志错落栅格、印刷式分区标题、编号卡片，打破呆板对齐
视觉模块：新增衬线大字横向传送带、深色反白区块，强化层次
氛围细节：全局纸纹噪点 + 暖色径向光斑，弱化屏幕冰冷感
模块样式：FAQ采用报纸双线分割，替代传统卡片样式
